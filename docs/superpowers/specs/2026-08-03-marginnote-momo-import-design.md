# MarginNote 导入墨墨单词书设计

## 目标

提供一个 MarginNote 插件窗口：将当前脑图中已选单词卡片标题里的单词原型，批量导入用户指定的墨墨背单词单词书。

## 范围

功能面向由 OhMyMN AutoComplete 生成的单词卡片。AutoComplete 会把单词原型放在标题首位，并以分号分隔其余词形。例如：

`shrink; shrank; shrunk; shrinking; shrinks`

会导入 `shrink`。

插件不会为任意英文标题猜测词根。若标题的首段不是有效英文单词，则跳过该卡片并在结果中报告。

## 用户流程

1. 用户在 MarginNote 脑图中选择一张或多张单词卡片。
2. 用户打开插件，点击“导入已选卡片”。
3. 插件读取所选卡片标题，提取并去重单词原型，展示预览：已选卡片数、可导入单词数、跳过数和单词列表。
4. 用户确认导入。插件将单词批量写入已配置的墨墨目标单词书，并分别报告成功、重复和失败的单词。

插件窗口提供“设置”入口，其中包含被遮蔽显示的墨墨 Bearer Token 输入框和必填的目标单词书 ID 输入框。两项配置只存储在本机插件配置中；Token 不会写入卡片、导出或日志。

## 数据规则

`extractLemma(title)` 会先清理标题首尾空白，再以英文或中文分号分割，只取第一个非空片段。该片段会去除首尾空白、转换为小写，并仅在符合“英文字母，内部可含撇号或连字符”的规则时接受。导入集合按大小写无关的方式去重，并保留卡片原始顺序。

选区适配器只负责从 MarginNote 原生多选上下文提供卡片标题；它与标题解析器隔离，因此无需 MarginNote 运行时也可测试标题规则。

## 墨墨集成

集成使用用户自己的墨墨官方开放 API Bearer Token。墨墨客户端接收配置的目标单词书 ID，并只调用该单词书对应的官方“添加单词”接口。在用户确认预览前，不发送任何网络请求。

请求将串行或分批执行，以遵守墨墨公开的频控：10 秒最多 20 次、60 秒最多 40 次。每个单词都独立记录结果。认证失败时立即停止并提示更新 Token；目标单词书无权限或不存在时停止，并保留未处理单词；临时网络错误会将失败单词显示在结果页供重试。插件不回滚已被墨墨成功接收的单词。

## 界面与错误处理

插件作为普通 MarginNote 插件窗口打开。未完成 Token 和目标单词书 ID 配置前，主导入命令不可用。无选中卡片、不支持的标题、空预览、取消确认和 API 失败都会显示明确的原生提示或结果界面。

结果界面支持将失败单词按每行一个词复制到剪贴板，以便 API 不可用时手动导入。

## 测试

标题解析测试覆盖常规 AutoComplete 标题、空白、中文分号、重复词根、不合法首段，以及含连字符或撇号的有效英文词。导入编排测试覆盖预览统计、确认前不发送网络请求、逐词结果统计、频控排队、认证失败和部分失败。墨墨传输层会在确定精确 OpenAPI 操作后，使用已记录的请求和响应结构进行测试。

## 非目标

首版不修改 OhMyMN 卡片，不从散文式标题推导词根，不将墨墨中的删除操作反向同步到 MarginNote，也不支持墨墨记忆卡。
