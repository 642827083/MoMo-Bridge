# 【第三方 MN4 插件】MoMo Import——批量导入单词和例句到墨墨背单词 #Ver 2.3.1#

## 插件简介

MoMo Import 是一款连接 MarginNote 与墨墨背单词的第三方插件。

在 MarginNote 脑图中批量选中单词卡片后，插件可以读取卡片标题中的单词原型，将单词批量添加到指定的墨墨云词本；如果卡片中包含英文句子和中文翻译，还可以将它们作为墨墨例句一并上传。

插件主要适配使用 **OhMyMN AutoComplete** 制作的单词卡片，适合在阅读时积累生词，并希望把单词和原文例句同步到墨墨背单词的用户。

> 当前版本：2.1.0  
> 作者：乔木Joe  
> 最低支持：MarginNote 4.2.3

## 功能概览

- 批量读取脑图选中的单词卡片
- 识别 AutoComplete 标题中的单词原型
- 添加单词到指定墨墨云词本
- 上传英文例句和中文翻译
- 例句同时关联单词原型和句中变形词
- 支持同一个单词添加多个不同例句
- 自动检查重复单词和重复例句
- 根据卡片标签生成例句来源
- 自动修复部分英文单词缺少空格的问题
- 可以只添加单词、只添加例句或同时添加
- 可以把识别到的单词直接加入墨墨背诵列表
- 支持将已在背诵列表中的单词提前到当前复习
- 提供例句数量限制和请求频率保护

## 单词卡片格式

推荐使用 OhMyMN AutoComplete 制作单词卡片。

例如卡片标题为：

```text
shrink; shrank; shrunk; shrinking; shrinks
```

插件会将第一个分号片段识别为单词原型：

```text
shrink
```

其他示例：

```text
sweep; swept; sweeping; sweeps → sweep
period; periods → period
handicap; handicapped; handicapping → handicap
```

支持英文分号、中文分号、标题标点、含连字符的单词以及大小写无关去重。

## 例句卡片格式

```text
标题：
sweep; swept; sweeping; sweeps

英文摘录：
Foreign-made cars and textiles were sweeping into the domestic market.

中文评论：
外国制造的汽车和纺织品涌入国内市场。
```

插件会识别单词原型 `sweep`、句中词形 `sweeping`、英文原句和中文翻译。

## 重要说明

插件读取 AutoComplete 标题中的第一个词形，不会对只有 `went`、`goes`、`children` 等单独词形的标题自行猜测原型。为了稳定识别，建议使用原型在前的 AutoComplete 标题。

[details="批量识别脑图卡片（点击展开）"]

插件支持在 MarginNote 脑图中同时选择多张单词卡片，并读取：

- 卡片标题
- 卡片摘录
- 文字评论
- 卡片末尾的标签行

同时兼容 MarginNote 返回的原生数组、字典对象、桥接属性和嵌套脑图节点。

如果卡片没有被正常识别，插件会提供已选卡片数量、标题样例和未识别完整例句的卡片列表，方便直接找到具体卡片。

[/details]

[details="添加单词到墨墨云词本（点击展开）"]

填写墨墨 Token 后，点击“加载词本”，插件会读取账号中的云词本列表。列表无法读取时，也可以直接填写云词本 ID。

导入前会检查目标词本中的已有单词：

- 已存在的单词不会重复添加
- 自动清理相同单词的重复行
- 忽略大小写差异
- 保持单词第一次出现的顺序

提交后会重新读取云词本，分别显示：

```text
单词成功
单词已存在
单词失败
```

失败单词可以一键复制。

墨墨开放 API 目前不能直接修改每日背诵计划。插件负责把单词添加到云词本，之后需要在墨墨中打开该词本并自行加入背诵。

[/details]

[details="上传例句和中文翻译（点击展开）"]

插件会从卡片摘录和评论中寻找真正包含标题单词或词形的英文句子，并把最后一条有效中文内容作为翻译。

如果句中出现的是 `sweeping`，卡片原型是 `sweep`，插件会同时查询 `sweep` 和 `sweeping` 对应的墨墨词条，并尝试将例句关联到两个词条，减少“例句必须包含原单词或原单词的变形”错误。

同一个单词可以上传多个不同例句。完全相同的英文例句和中文翻译不会重复创建。插件会在上传前检查已有例句，并在上传后重新读取进行核验。

结果会分别显示：

```text
例句成功
例句已存在
例句失败
```

失败时还会显示首条失败原因。

[/details]

[details="卡片标签与例句来源（点击展开）"]

如果卡片末尾包含纯标签行：

```text
#2000EN #阅读 #Text2
```

插件不会把标签误识别为翻译，并会把例句来源设置为：

```text
2000EN阅读Text2
```

没有标签时，例句来源留空。

目前上传到墨墨的例句标签固定为“考研”。卡片标签决定的是例句来源，不是墨墨例句标签。

插件没有公开或私有切换选项，例句的公开范围和展示方式由墨墨客户端及开放 API 规则决定。

[/details]

[details="缺少空格的自动修复（点击展开）"]

AutoComplete 或原文处理过程中，偶尔可能出现：

```text
theword
wordof
destroyedthe
```

在能够明确判断边界时，插件会自动修复为：

```text
the word
word of
destroyed the
```

该功能只处理当前单词词形与常见英文功能词之间能够明确识别的粘连，不会随意拆分普通英文单词。

[/details]

[details="导入内容多选与背诵（点击展开）"]

插件提供三个可以独立勾选的选项，并保持在同一行：

- 添加单词
- 添加例句
- 添加背诵

三项可以任意组合。全部不勾选时无法继续。

只添加例句或背诵时不需要选择目标云词本，但对应单词必须能够被墨墨查询到。

勾选“添加背诵”后，会在其下方显示“同时提前复习”附属选项。该选项默认关闭；取消“添加背诵”时会自动取消并隐藏。

“添加背诵”使用墨墨学习数据公测接口，需要在墨墨 App 中开启自动同步。“同时提前复习”会调用独立的提前复习接口，墨墨要求账号达到 10 级，且可能改变当前学习计划。

插件会分别显示背诵新增、未新增、未找到词条，以及提前复习成功、未提前和具体接口错误。墨墨没有返回逐个单词的未新增原因时，插件只提供可能原因，不会将其误报为失败。

[/details]

[details="例句数量与频率限制（点击展开）"]

墨墨开放 API 有请求频率限制。上传一条例句可能需要查询单词 ID、读取已有例句、提交例句和重新核验等多次请求。

为了减少 `Too many request`：

- 每批最多上传 10 条例句
- 超过 10 条时自动拆分为多个批次，无需手动减少卡片
- 自动控制各批次和请求之间的间隔
- 请求过于频繁时自动等待后重试，并显示中文进度
- 网络中断、请求超时或服务暂时不可用时自动短暂等待后重试
- 单词和例句分别统计结果

预览区域最多展示前 8 条，确认时仍会通过批量任务队列上传本次识别到的全部例句。

[/details]

[details="Token 与网络说明（点击展开）"]

墨墨开放 API 开启路径：

```text
墨墨背单词 → 我的 → 更多设置 → 实验功能 → 开放 API
```

墨墨开放平台：

https://open.maimemo.com/#/

插件支持带或不带 `Bearer` 前缀的 Token。Token 和目标词本 ID 保存在本机插件设置中，不会写入脑图卡片或运行日志。

“如何获取墨墨 Token”会在插件窗口外打开，避免进入网页后无法返回插件面板。

插件还增加了 MarginNote 原生网络请求适配、请求超时、缓存控制、墨墨错误信息保留、接口路径兼容和导入结果核验。

请勿把自己的 Token 分享给其他人。

## 使用方法

1. 安装并启用 MoMo Import。
2. 点击插件图标打开面板。
3. 填写自己的墨墨开放 API Token。
4. 按需勾选“添加单词”“添加例句”和“添加背诵”。
5. 如果勾选“添加背诵”，可选择是否“同时提前复习”。
6. 如果需要添加单词，点击“加载词本”并选择目标云词本。
7. 在 MarginNote 脑图中批量选中单词卡片。
8. 回到插件，点击“识别已选卡片”。
9. 检查识别到的单词、例句、翻译和来源。
10. 点击确认按钮开始导入。
11. 查看单词、例句、背诵和提前复习结果。

- 修复原型例句已成功上传，但变形词未找到墨墨词条 ID 时，整条例句仍被误报为失败的问题。

### 如何把单词直接加入每日背诵？

勾选“添加背诵”即可直接加入墨墨背诵列表。该功能使用公测接口，请先在墨墨 App 中开启自动同步。未新增通常表示单词已在背诵列表中，或墨墨单词上限不足。

### 为什么提前复习没有成功？

请确认墨墨账号已经达到 10 级、App 已开启自动同步、Token 属于当前账号，并检查插件显示的“未提前原因”。如果接口成功但数量未全部提前，可能是单词尚未加入背诵列表、已经处于当前学习安排中，或墨墨公测接口未完成处理。

### 为什么例句显示“已存在”？

墨墨中已经存在完全相同的英文例句和中文翻译，插件不会重复创建。

### 为什么例句识别失败？

请检查卡片中是否包含完整英文句子和中文翻译，英文句子是否包含标题中的原型或词形，以及标题是否为 AutoComplete 格式。

### 为什么组合词或短语上传失败？

墨墨可能没有收录该内容，或无法返回对应的词条 ID 和释义。

### 一次可以上传多少例句？

可以一次选择几十张卡片。插件会将识别到的例句按每批最多 10 条自动上传；遇到限流或短暂网络问题时会自动等待重试。大批量任务需要一定处理时间，请保持插件面板和网络连接正常。

### 导入失败后需要重新选择全部卡片吗？

不需要。插件会在本机保留最近 20 次导入记录，可展开存在失败项的记录并点击“仅重试失败项”。失败的云词本单词和例句会单独重试；由于墨墨背诵接口只返回数量，背诵失败时只能重新提交该次相关单词。

### 导入历史会保存 Token 吗？

不会。历史记录仅保存完成失败重试所需的单词、例句、导入选项和结果，不记录墨墨 Token。
