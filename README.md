## 大批量例句任务队列

- 支持一次选择几十张脑图卡片，不再限制一次只能确认 10 条例句
- 例句自动按每批最多 10 条依次上传
- 添加云词本单词和添加背诵仍各执行一次，不会因例句分批而重复添加
- 上传过程中显示当前批次、总批次数和已处理例句数量
- 完成后显示本次批量任务的总批次数和自动重试次数

## 限流等待和失败重试

- 使用 MarginNote 原生定时器执行真实等待，兼容插件的 JavaScriptCore 运行环境
- 遇到墨墨 `Too many request` 或频率限制时，自动等待约 1 分钟后重试
- 遇到网络中断、请求超时或服务端临时异常时，按短间隔自动重试
- 参数错误、权限错误等不可恢复问题不会盲目重试
- 某一批最终失败时显示失败批次和原因，后续未提交例句计入失败项，不会误报全部完成

## 导入历史与仅重试失败项

- 自动保存最近 20 次批量导入和失败项重试结果
- 记录所选导入内容、单词结果、例句结果、背诵结果和失败原因
- 历史记录保存在本机插件数据目录，不记录墨墨 Token
- 即使关闭插件面板，重新打开后仍可查看历史记录
- 支持直接从历史记录中仅重试失败的云词本单词和例句，无需重新选择原卡片
- 每次重试结果会另存为一条历史记录，方便继续核对
- 墨墨背诵接口只返回数量，无法指出具体失败单词；需要重试背诵时会重新提交该次相关单词，并在界面中明确说明这一限制
