## 添加背诵

- 新增“添加背诵”复选框
- “添加单词”“添加例句”“添加背诵”三个主选项保持同一行
- 三个主选项支持任意组合，也可以仅添加背诵
- 自动查询单词对应的墨墨词条 ID
- 通过墨墨学习数据公测接口将单词加入背诵列表
- 不选择“添加单词”时，无需选择目标云词本
- 显示背诵新增、未新增和未找到词条数量
- 未新增时提供“已在背诵列表或单词上限不足”等可能原因说明
- 提醒用户在墨墨 App 中开启自动同步

## 提前复习

- 新增“同时提前复习”附属复选框，默认关闭
- 只有勾选“添加背诵”后才显示
- 取消“添加背诵”时自动取消并隐藏提前复习选项
- 使用墨墨独立的 `/memo/study/advance_study` 公测接口
- 支持将原本已在背诵列表中的单词提前到当前复习
- 显示接口返回的真实“成功提前”和“未提前”数量
- 增加“未提前原因”独立提示
- 将 `Permission denied` 转换为明确中文说明，提示账号需达到 10 级
- 保留其他墨墨接口、限流、Token 和网络错误信息
